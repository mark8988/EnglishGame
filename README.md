# 冬日暖屋 · English Cottage

以照片中的 224 個單字與片語製作的繁體中文英文學習遊戲。完整詞表見 [vocabulary.md](vocabulary.md)。

## 開始遊戲

無需安裝應用依賴。使用 Python 3：

```sh
cd /workspace/EnglishGame
python3 -m http.server 8000 --bind 0.0.0.0
```

用瀏覽器開啟伺服器。答對題目依題型可得 5、8、12、16 或 20 金幣，商店中可修屋頂、窗戶，購買熱湯和家具。商店新增 100 項食衣住行育樂商品，加上寵物用品共 123 項，食品可重複購買，家具與擺飾可自由布置。每次作答消耗少量飽足和溫暖，離線不消耗；狀態過低時有緊急救援，不會永久失敗。全部十項永久物品購齊即完成暖屋目標，可繼續練習單字。

進度使用瀏覽器 localStorage，無帳號或後端。不同裝置不會同步。發音使用瀏覽器語音引擎，聲音支援依裝置而異。Google 字型載入失敗會使用系統字型。

## 新增玩法

- 每五題依序為英翻中（5）、看中文輸入英文（8）、聽音選中文（12）、聽音辨英文（16）、聽音拼字（20）。答錯不獎勵；聽力題按播放才發音，可重聽。瀏覽器不支援語音時回到閱讀題型。
- 永久物品每次作答耐久減 1%，歸零後效果暫停、展示移除，需以原價重新購買。離線不折舊。舊存檔預設物品耐久為 100%。
- 三格菜圃可種胡蘿蔔、番茄和玉米，分別作答 3、4、5 題後可收成並補充飽足。
- 製作參觀連結後分享給朋友，朋友會看到分享當下的小屋及收藏快照。沒有即時多人、帳號或訪客通知；參觀不會修改彼此存檔。連結須使用可供朋友存取的部署網址。

## 房間與寵物

- 小屋有 11 個獨立空間：客廳、廚房、房間一至三、更衣室、書房、臥室、浴室、陽台、車庫。上方選單或平面圖可切換房間，購買家具與擺飾會自動放入目前房間，在商店點背包收藏可移入或收回，不限制四件。同一件物品不重複放置。舊版收藏會移到客廳。
- 「奇幻寵物之家」共 28 種可選，可同時領養最多三隻不同物種。原有種類包含：小貓、小狗、月光兔、獵豹、外星人、迷你龍、飛碟與星空章魚。寵物可改名並出現在小屋內。
- 商店「寵物用品」新增 12 項商品。飼料與清潔品購買後存入寵物背包，再指定寵物使用；每次消耗一份。衣服、玩具與生活用品購買後可裝備，同一件只能裝備一隻寵物，耐久歸零後需重購。
- 每次作答寵物飽足減 2、清潔減 1，心情隨照顧狀況下降；可陪玩恢復心情。自動餵食碗讓每題飽足只減 1，雲朵床讓清潔每兩題才減 1，玩具提升陪玩效果。離線不消耗狀態，寵物不會死亡。衣服供裝扮使用。
- 朋友參觀快照會包含寵物名字與種類；不提供即時多人互動。

新增 20 種寵物：極光狐狸、竹林熊貓、圍巾企鵝、星夜貓頭鷹、栗子刺蝟、布丁倉鼠、泡泡水獺、溫泉水豚、手套浣熊、松果松鼠、翡翠小龜、彩虹鸚鵡、棉花糖獨角獸、餅乾小恐龍、齒輪機器人、棉被小幽靈、果汁史萊姆、火花鳳凰、雷雨小雲、蘑菇精靈。

看中文寫英文與聽音拼字每五題各出現一次，必須輸入完整單字或片語，沒有選項；看中文寫英文不提供發音提示。空白送出不扣回合，答錯顯示正確答案。忽略大小寫與多餘空白，接受詞表中的英美拼字與 have to / have got to 等變體。

房屋平面圖顯示全部 11 個空間與走廊，以粉紫色、金色外框及「你在這裡」標出目前位置。可點選房間或用鍵盤 Tab / Enter 切換，會同步更新室內畫面與目前位置，並儲存最後停留的房間。格局為遊戲示意，非實際比例。

## 可愛插畫

莉莉使用原創生成的透明背景 Q 版角色圖，金髮粉色髮尾、大眼睛與冬季服裝；房屋、平面圖、家具、商品及 28 種寵物使用統一粉彩配色。所有圖片存於 `assets/art/`，執行時不需要遠端圖片服務。`scripts/generate-art.py` 可重新產生原創 SVG 圖示（需 Node.js 與 Python 3）；不會重製莉莉的 PNG。`art.js` 負責替換介面裝飾圖示並保留替代文字。

## 室內繪本場景與版面

主畫面以目前房間的室內視角為主，不再顯示房屋外觀。`assets/rooms/empty-0.png` 至 `empty-2.png` 是原創生成的室內繪本圖集，每張為 2 × 2 等分，依 `ROOMS` 順序呈現 11 個不同空間。透過 CSS 背景定位顯示單一房間，不需要外部圖片服務。背景是空的卡通繪本房間，僅有固定門窗、牆面與地板，不含家具。家具與擺飾只會在購買後加入場景，莉莉、寵物與修繕提示另疊在場景上。

桌面使用大幅室內圖搭配右側任務，照顧與菜園移到下方卡片；手機優先顯示室內圖，任務置於其後。可用場景上方選單快速換房，或展開下方平面圖。答題獎勵依五種難度為 5、8、12、16、20 金幣。

## 拖曳布置

購買家具、擺飾或可展示的耐用品後，會自動放進目前選定的房間。滑鼠或觸控按住物品拖曳，位置會自動保存；可 Tab 選取物品後用方向鍵微調，Shift + 方向鍵可較大幅移動。物品不會拖出房間邊界，並使用相對座標適應桌面與手機。

選取物品後按「收回背包」可暫時移除，或在商店背包點「放入此房／移入此房」搬到目前房間。一件物品只會放在一處，沒有四件展示限制。食物仍用於補充飽足、寵物消耗品存入寵物背包、衣服存入換裝衣櫃、屋頂窗戶地板屬於固定修繕，不會生成可拖曳物件。物品損壞後隱藏，重新購買會放入目前房間。

`placement.js` 管理座標、拖曳、背包與舊存檔轉換。舊版各房間收藏保留位置歸屬，原固定家具保留原本房間，未布置的物品仍在背包。朋友參觀快照會保留目前物品位置，訪客不能修改主人的布局。

## 莉莉換裝

商店「衣」類的 16 件衣物與「修繕」中的大衣共解鎖 17 款完整穿搭。購買會立即穿上，之後可在「衣櫃」頁籤預覽並任意切換已購買且未損壞的造型，也可免費換回原本造型。每次選擇一款完整穿搭；帽子、圍巾等會以對應搭配造型呈現。

換裝會替換莉莉整個身體的穿著插畫，保留角色身份，不是在房間或身體上貼商品圖示。原有衣服收藏會移入衣櫃並保留耐久，舊房間中的衣服貼圖會移除，家具不受影響。損壞的衣物無法穿用，當前穿搭損壞時回復原本造型。換裝選擇會儲存在本機存檔，朋友參觀快照也包含當時穿搭。

`wardrobe.js` 管理穿搭、預覽與舊存檔遷移；`assets/outfits/looks-0.png` 至 `looks-2.png` 為原創角色換裝圖集，每張 3 × 2 格，使用各圖集實際比例顯示，沒有遠端圖片依賴。

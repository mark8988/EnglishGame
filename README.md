# 冬日暖屋 · English Cottage

以照片中的 224 個單字與片語製作的繁體中文英文學習遊戲。完整詞表見 [vocabulary.md](vocabulary.md)。

## 開始遊戲

無需安裝應用依賴。使用 Python 3：

```sh
cd /workspace/EnglishGame
python3 -m http.server 8000 --bind 0.0.0.0
```

用瀏覽器開啟伺服器。答對題目依題型可得 5、8、12、16 或 20 金幣，商店中可修屋頂、窗戶，購買熱湯和家具。商店新增 100 項食衣住行育樂商品，共 111 項，食品可重複購買，其他新增物品可收藏並選擇最多四件展示。每次作答消耗少量飽足和溫暖，離線不消耗；狀態過低時有緊急救援，不會永久失敗。全部十項永久物品購齊即完成暖屋目標，可繼續練習單字。

進度使用瀏覽器 localStorage，無帳號或後端。不同裝置不會同步。發音使用瀏覽器語音引擎，聲音支援依裝置而異。Google 字型載入失敗會使用系統字型。

## 新增玩法

- 每五題依序為英翻中（5）、看中文輸入英文（8）、聽音選中文（12）、聽音辨英文（16）、聽音拼字（20）。答錯不獎勵；聽力題按播放才發音，可重聽。瀏覽器不支援語音時回到閱讀題型。
- 永久物品每次作答耐久減 1%，歸零後效果暫停、展示移除，需以原價重新購買。離線不折舊。舊存檔預設物品耐久為 100%。
- 三格菜圃可種胡蘿蔔、番茄和玉米，分別作答 3、4、5 題後可收成並補充飽足。
- 製作參觀連結後分享給朋友，朋友會看到分享當下的小屋及收藏快照。沒有即時多人、帳號或訪客通知；參觀不會修改彼此存檔。連結須使用可供朋友存取的部署網址。

## 房間與寵物

- 小屋有 11 個獨立空間：客廳、廚房、房間一至三、更衣室、書房、臥室、浴室、陽台、車庫。上方按鈕切換房間，在商店點收藏品可移入目前房間，每間最多四件。同一件物品不重複放置。舊版收藏會移到客廳。
- 「奇幻寵物之家」共 28 種可選，可同時領養最多三隻不同物種。原有種類包含：小貓、小狗、月光兔、獵豹、外星人、迷你龍、飛碟與星空章魚。寵物可改名並出現在小屋內。
- 商店「寵物用品」新增 12 項商品。飼料與清潔品購買後存入寵物背包，再指定寵物使用；每次消耗一份。衣服、玩具與生活用品購買後可裝備，同一件只能裝備一隻寵物，耐久歸零後需重購。
- 每次作答寵物飽足減 2、清潔減 1，心情隨照顧狀況下降；可陪玩恢復心情。自動餵食碗讓每題飽足只減 1，雲朵床讓清潔每兩題才減 1，玩具提升陪玩效果。離線不消耗狀態，寵物不會死亡。衣服供裝扮使用。
- 朋友參觀快照會包含寵物名字與種類；不提供即時多人互動。

新增 20 種寵物：極光狐狸、竹林熊貓、圍巾企鵝、星夜貓頭鷹、栗子刺蝟、布丁倉鼠、泡泡水獺、溫泉水豚、手套浣熊、松果松鼠、翡翠小龜、彩虹鸚鵡、棉花糖獨角獸、餅乾小恐龍、齒輪機器人、棉被小幽靈、果汁史萊姆、火花鳳凰、雷雨小雲、蘑菇精靈。

看中文寫英文與聽音拼字每五題各出現一次，必須輸入完整單字或片語，沒有選項；看中文寫英文不提供發音提示。空白送出不扣回合，答錯顯示正確答案。忽略大小寫與多餘空白，接受詞表中的英美拼字與 have to / have got to 等變體。

房屋平面圖顯示全部 11 個空間與走廊，以深綠色、金色外框及「你在這裡」標出目前位置。可點選房間或用鍵盤 Tab / Enter 切換，會同步更新室內畫面與目前位置，並儲存最後停留的房間。格局為遊戲示意，非實際比例。

## 可愛插畫

莉莉使用原創生成的透明背景 Q 版角色圖，金髮粉色髮尾、大眼睛與冬季服裝；房屋、平面圖、家具、商品及 28 種寵物使用統一粉彩配色。所有圖片存於 `assets/art/`，執行時不需要遠端圖片服務。`scripts/generate-art.py` 可重新產生原創 SVG 圖示（需 Node.js 與 Python 3）；不會重製莉莉的 PNG。`art.js` 負責替換介面裝飾圖示並保留替代文字。

## 室內繪本場景與版面

主畫面以目前房間的室內視角為主，不再顯示房屋外觀。`assets/rooms/sheet-0.png` 至 `sheet-2.png` 是原創生成的室內繪本圖集，每張為 2 × 2 等分，依 `ROOMS` 順序呈現 11 個不同空間。透過 CSS 背景定位顯示單一房間，不需要外部圖片服務。背景中的基礎陳設屬於場景裝飾；購買收藏、莉莉、寵物與修繕提示另疊在場景上。

桌面使用大幅室內圖搭配右側任務，照顧與菜園移到下方卡片；手機優先顯示室內圖，任務置於其後。可用場景上方選單快速換房，或展開下方平面圖。答題獎勵依五種難度為 5、8、12、16、20 金幣。
